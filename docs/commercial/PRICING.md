## 🔄 Upgrade & Downgrade Policy

### Upgrading

**Immediate Benefits:**
- ✅ New features available instantly
- ✅ Pro-rated credit for current plan
- ✅ No service interruption
- ✅ Limits updated immediately

**How to Upgrade:**
1. Use `/premium upgrade` in Discord
2. Choose new plan
3. Complete payment
4. Enjoy new features instantly

### Downgrading

**Effective Date:**
- Changes take effect at end of current billing period
- Continue enjoying current features until then
- No partial refunds for downgrades

**How to Downgrade:**
1. Use `/premium change-plan` in Discord
2. Select lower tier
3. Confirm downgrade
4. Change applies next billing cycle

**What Happens:**
- Playlists over new limit are preserved (read-only)
- Excess queue items removed at next session
- Feature access removed at cycle end
- No data loss
